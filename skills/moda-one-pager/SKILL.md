**This skill was renamed — load `moda-document`.**

- One page or fifty: one-pager, report, brief, whitepaper, proposal, infographic → moda-document.
- Print pieces (poster, flyer, brochure, menu, resume, certificate, card) → moda-document-print.
- The name went because "one-pager" mis-routed multi-page documents; the craft moved intact.

Nothing here is maintained. This tombstone ships for one release so pinned installs still resolve
the name; then the skill is deleted, with no compatibility path after it.
